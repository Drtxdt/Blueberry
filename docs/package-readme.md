# Blueberry Windows x64

运行 `blueberry.exe` 进入 PowerShell 补全会话。输入 `git log --` 试用菜单：方向键选择，Tab 填入，Esc 关闭。也可以运行 `blueberry.exe doctor --json` 查看当前配置和运行环境。

支持 Windows PowerShell 5.1（PSReadLine 2.0.0 或 2.4.5）和 PowerShell 7（PSReadLine 2.4.5）。核心包无需安装增强 Terminal 组件。安装、启用自动启动、升级和回滚见[安装指南](docs/installation.md)。

本包版本与文件摘要见 [release.json](release.json)，本版变化见[版本说明](RELEASE-NOTES.md)。其他版本可从 [GitHub Releases](https://github.com/Drtxdt/Blueberry/releases) 获取。
