## 原始签名命令的安全复核

只在本次临时测试会话中运行以下准备代码，将 `ssh-keygen` 定义为参数与标准输入记录函数。不写 profile；关闭测试会话即移除函数。自动夹具见 `tests/input_protocol.rs`。

```powershell
$global:blueberryAcceptanceLog = Join-Path $env:TEMP ('blueberry-signing-' + [guid]::NewGuid() + '.jsonl')
function global:ssh-keygen {
    @{ arguments=@($args); stdin=@($input) } | ConvertTo-Json -Compress |
        Add-Content -LiteralPath $global:blueberryAcceptanceLog -Encoding UTF8
}
Get-Command ssh-keygen | Select-Object Name,CommandType
```

确认显示 Function 后，逐字输入或粘贴以下原始命令；这时不调用真实签名程序、不访问私钥。新建嵌套 Shell 后函数不会自动继承，须先重新执行准备代码和身份检查。

```powershell
echo -n '24e25ad07ecdde7e5ed2ed2bb9a44578187ee59fec6b209dbd34f725350b3c55' | ssh-keygen -Y sign -n gitea -f /path_to_your_privkey
```

通过 `Get-Content -LiteralPath $global:blueberryAcceptanceLog` 保存记录。每次非空命令确认应新增一行；参数依次为 `-Y`、`sign`、`-n`、`gitea`、`-f`、`/path_to_your_privkey`，标准输入为上述字符串，不能包含 Enter 协议后缀。

分别逐字输入、整段粘贴、连续 Enter，并在外部程序及嵌套 Shell 返回后重复。保存实际编辑行、记录函数收到的参数和标准输入及调用次数。Enter 的按下／释放不应让非空命令重复执行；结束后空行 Enter 保留 PowerShell 原本语义。形似转义序列的普通文本仍须原样保留。
