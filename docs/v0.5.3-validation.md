# Blueberry 0.5.3 候选验收

本版为可靠性候选，尚未公开。下列状态与实际候选包绑定；未执行不能记为通过。

## 交付政策

- 功能、安装生命周期、包身份与自动回归必须通过。
- 用户选择“修复先交付，性能继续”：本版性能目标可延期，v0.6 仍须正式验收。
- 用户在本机人工测试；本版没有 Windows Terminal 人工豁免。
- 用户短期无法招募测试人员：0.5.3／0.6.0 外部试用未执行，不作为本轮门槛。

## 自动证据与候选身份

候选 ZIP、EXE、源码提交、CI run、SHA-256 及实际自动结果在构建后补齐。
本地开发测试与最终 CI 包验收分开记录，不以不同二进制相互替代。
大型原始记录存放于 `artifacts/` 并通过固定身份的 Actions 工件交付；政策见
[工件保留与性能采集](benchmark-artifacts.md)。
