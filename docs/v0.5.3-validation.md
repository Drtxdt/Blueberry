## 交付政策

- 功能、安装生命周期、包身份与自动回归必须通过。
- 用户选择“修复先交付，性能继续”：本版性能目标可延期，v0.6 仍须正式验收。
- 用户在本机人工测试；本版没有 Windows Terminal 人工豁免。
- 用户短期无法招募测试人员：0.5.3／0.6.0 外部试用未执行，不作为本轮门槛。
