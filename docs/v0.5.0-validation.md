## 发布阻断项

第三轮 PR CI `37293088747` 的核心三平台、两条上游测试线、PS7/OSC 和原生鼠标通过。输入夹具在 plain PowerShell 中已失败：旧 ConPTY 会在单次写入结束时冲刷不完整转义序列（[Microsoft #4037](https://github.com/microsoft/terminal/issues/4037)），因此外层夹具改为发送完整 Win32 记录；Blueberry 解码器仍保留逐字节分段单元测试。CI 现在保留原始输入字节、实际缓冲区和执行检查点。三组合输入回归本地通过。另一项启动超时来自探针等待提示符时丢弃先到达的完整命令快照；现按任意顺序收齐启动事件，PS5.1/2.4.5 的 OSC／pipe 各 11 项终端回归通过。此次本地修复仍须由后续 CI 验证。

- 后续修改在 CI 上的完整回归和安装生命周期；首轮失败的 CI 尚未被成功候选替代。
