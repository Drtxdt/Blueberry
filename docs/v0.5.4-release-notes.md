# Blueberry 0.5.4

Windows x64，支持 Windows PowerShell 5.1 和 PowerShell 7。

- 路径无法访问时，补全菜单显示具体原因；Tab 仍可使用原生补全。
- 命令索引采用当前 PowerShell 报告的 PATH 和 PATHEXT。环境改变后不再接受旧扫描的结果。
- 可分别诊断首键回显、首批候选和完整菜单的等待时间。

核心包可以单独安装，增强 Terminal 组件为可选项。安装、卸载和回滚见[安装指南](docs/installation.md)。公开版本及其验收资料见 [GitHub Releases](https://github.com/Drtxdt/Blueberry/releases)。
