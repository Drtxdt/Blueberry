# Blueberry 0.5.3

Windows x64 功能与可靠性更新。

- 默认安装核心包；增强 Windows Terminal 改为独立可选组件。
- 增加官方 Windows Terminal 专用入口管理、能力诊断与普通终端菜单区域。
- 完善工具页快捷键、共享配置保存、参数引用、上下文表单及 Git / uv / Cargo 工作流。
- 改进安装事务、升级和回滚；增强组件可单独安装、卸载和重新安装并保留设置。

## 下载

日常使用下载 `blueberry-v0.5.3-windows-x64.zip`。增强终端按需下载 `blueberry-terminal-component-v1.24.12741.0-native4-b1a2d3f-windows-x64.zip`。同时提供安装脚本、清单和 SHA-256 校验文件。
